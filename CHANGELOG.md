# Changelog

## [0.2.0] - 2026-11-14

- Scanning the setup code uses the **inner camera** now; **L or R** switches to the outer one (also while scanning). The bottom line says which one is on.

## [0.1.1] - 2026-11-09

- An installable `quire.cia` (for FBI) is now published next to the `.3dsx`.

## [0.1.0] - 2026-11-09

- First version, read-only: sign in by scanning the phone setup code from Quire on your computer with the 3DS camera,
  then see today (lessons, shifts, events, routines, water), open tasks and your notes, synced from your quire-server.
